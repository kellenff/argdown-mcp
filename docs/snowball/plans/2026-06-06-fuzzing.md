# Parser Fuzzing Implementation Plan

**Goal:** A cargo-fuzz harness fuzzing `parse` and the full Layer-B pipeline for
no-panic + structural invariants, with a seed corpus and a nightly CI smoke-run.

**Spec:** `docs/snowball/specs/2026-06-06-fuzzing-design.md`. **Branch:** commit
directly to `main` (additive; the `fuzz/` crate is out-of-workspace, so no
version bump and no effect on the stable gate).

---

### Task 1: fuzz/ crate + targets + seeds
- [ ] `fuzz/Cargo.toml` — own workspace (`[workspace]`), `libfuzzer-sys` + the
  three crates, two `[[bin]]` targets (`parse`, `model`).
- [ ] `fuzz/fuzz_targets/parse.rs` — no-panic + determinism + `check_document_spans`.
- [ ] `fuzz/fuzz_targets/model.rs` — Layer B no-panic + determinism + AF/labelling invariants.
- [ ] `fuzz/seeds/*.argdown` — one valid doc per construct + a mixed doc (from the bench corpus).
- [ ] `fuzz/.gitignore` — `target/ corpus/ artifacts/ coverage/`.

### Task 2: Verify
- [ ] `cargo +nightly fuzz build` compiles both targets.
- [ ] Seed the gitignored corpus, then run each target time-boxed (never point a
  run at `fuzz/seeds/` — libFuzzer would write into it):
  `mkdir -p fuzz/corpus/parse && cp fuzz/seeds/*.argdown fuzz/corpus/parse/ &&
  cargo +nightly fuzz run parse -- -max_total_time=20` (same for `model`) — both
  execute, find no crash.
- [ ] Root stable gate unaffected: `cargo fmt --all --check`, `cargo clippy
  --workspace --all-targets --locked -- -D warnings`, `cargo test --workspace --locked` still green.

### Task 3: CI workflow + commit
- [ ] `.github/workflows/fuzz.yml` — nightly + cargo-fuzz; build + time-boxed run
  per target; on PR/push to `main`, daily `schedule`, `workflow_dispatch`; upload
  crash artifacts on failure.
- [ ] Commit spec + plan + `fuzz/` + workflow to `main`.

Out-of-workspace cargo-fuzz crate, two full-pipeline targets with invariant
